# 床ピアノ

床に投影して、足でふむと音が鳴るドレミファソラシドの8鍵ピアノ（ブラウザだけで動きます）。

## 使い方
1. `index.html` をブラウザで開く（GitHub Pages でも可）
2. F キーで全画面（Esc キーで設定画面を開く／閉じる）
3. プロジェクターで床に投影

## 足の検出
- **床用タッチ／赤外線センサー**：タッチ・クリックとして届くのでそのまま使えます（同時に何人でもOK）
- **センサーがないとき**：Esc で設定を開いて「カメラを使う」。プレビューの黄色い枠を投影された鍵盤に合わせると、動きがあった列の音が鳴ります
- キーボード `A S D F G H J K` / `1〜8` でも鳴らせます

設定では鍵盤の色（カラー／全部白）、向き（回転）、文字（カタカナ／ひらがな）と大きさ、音量・音色なども変えられます。
